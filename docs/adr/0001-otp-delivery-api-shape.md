# OTP Delivery API Shape

Bifrost will expose a synchronous `POST /api/v1/otp/send/` endpoint whose only responsibility is to deliver an OTP WhatsApp template message to a **Turn Contact** identified by E.164 phone number, without owning OTP generation, validation, expiry, or resend policy. The endpoint will use Django REST Framework token authentication plus a custom `synch.send_otp` permission on the authenticated **API Caller**, will submit the message directly to Turn and return `200 OK` with a provider-agnostic `message_id` when Turn accepts it, and will enforce per-contact **Delivery Protection** with configurable settings backed by Django's database cache rather than new infrastructure or application-level OTP persistence. This records the deliberate choice to keep the public contract provider-agnostic while implementing directly against Turn, to fail fast on upstream errors without retries or idempotency guarantees, and to keep OTP delivery protection separate from patient sync and reminder suppression logic.
